## 4. Bugs found and fixed while verifying

| Bug | Impact | Fix |
|---|---|---|
| `LUT_3D_INPUT_RANGE` parsed with a 17-character offset | Range keywords failed; a cube with an input range would not load | Dedicated pair parser, keyword length taken from the literal |
| Input range parsed as three numbers | Same as above | `parsePair` (two values, per the format) |
| `DOMAIN_MIN/MAX` accepted inverted or 0..255 ranges | Nearly black output with no explanation | Validated per channel and bounded to ±4 |
| Non-finite colour entries reached the atlas packing | Silent black pixels | Rejected at read time with a message |
| `ImageReader` imported from `android.hardware` | Did not compile | `android.media.ImageReader` |
| Unreachable `catch (CameraAccessException)` clauses | Did not compile | Removed |
| `AssetManager` default source set hid the new assets | LUTs would be missing at runtime | `assets.srcDir("src/main/assets")` + a policy test |
| Release self-test accepted a 166 KB dispatch body | Publishing stopped once the APK grew | Test now asserts the guard rejects it |
| NaN fixture in the parser test was an unknown keyword, not an entry | Test asserted the wrong behaviour | Fixture corrected to a real entry |
| 90° orientation test assumed no translation | Wrong assertion, right matrix | Test now checks the transformed quad covers 0..1 |

## 5. Deliberately not done (and why)

| Feature | Why not in this stage |
|---|---|
| HDR+ burst capture/align/merge, night mode | Needs multi-frame capture plus a GPU alignment pipeline and a real-sensor comparison; cannot be validated on an emulator camera. |
| Super-resolution (ncnn/Vulkan) | Requires a native toolchain and model assets; would add an untested binary to the APK. |
| RAW/DNG, MAF/JPEG XL, `.craw` | No RAW output validation path here; the GPL-3.0 reference project could not be used under MIT anyway. |
| 4K/HDR video, Action Mode, dual video | Requires stronger HAL support and physical-device thermal testing; would be an unverified claim. |
| Histogram, level indicator, focus peaking | Planned with the Pro layout; the guides that exist are honest screen overlays. |
| In-app updater | Would add `INTERNET` to an app whose privacy promise is "no network"; design and options are in `docs/UPDATER.md`. |

## 6. Checksums

APK checksums are produced by CI at publish time and listed in `SHA256SUMS.txt` next to the
release. They are intentionally not written here: a checksum of a locally built or
non-published artifact would be misleading. Use
`https://github.com/m777m44/Camera-magic/releases/latest/download/Mahdi_Camera.apk` and
compare against the `SHA256SUMS.txt` of that same release.
